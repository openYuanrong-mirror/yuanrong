feature/distribute_env Buildkite

pipeline.yml 调用 pipeline.dynamic.yml 生成流水线。默认生成 12 个任务，面向 core、Rust 数据面、RRT 和 sandbox-sdk。

阶段任务产物或验证
构建Build X86 / Build arm控制面组件、既有拆分包和 openyuanrong-core；复用每个架构的一次 make all。
数据面Build Rust Data Plane amd64 / arm64Edge、Node Proxy、forward 二进制及 openyuanrong-data-plane wheel；单测、mock E2E 和静态链接检查。
RRTBuild RRT amd64 / arm64静态 rrt-runtime 二进制和 openyuanrong-rrt wheel。
镜像Build Image / Build Image arm控制面、节点和共享 RRT 镜像；RRT 镜像直接安装本次构建的 RRT wheel。
汇总Build Manifest多架构镜像清单、Helm 包及构建产物索引。
集群验证Test K8SEdge 控制入口、沙箱创建、idle timeout、sandbox-sdk direct/copy/tunnel/端口转发。
SDKBuild SDK Sandboxopenyuanrong-sandbox wheel 和 direct 路由契约测试。
发布Publish Wheels PyPI按发布配置上传 openyuanrong-sandbox；TestPyPI 与正式 PyPI 凭据分别配置。

依赖与开关

镜像任务依赖同架构的控制面、RRT 和数据面任务。Manifest 等待镜像及 sandbox-sdk 产物；Test K8S 等待镜像或 Manifest。集群验证使用现有并发锁串行执行。

  • ENABLE_LINUX_ARM=false：只生成 x86 侧构建与镜像任务。
  • ENABLE_SANDBOX_PACKAGE=false：只生成组件构建任务。
  • ENABLE_RRT_ONLY=true：只构建选定架构的 RRT。
  • ENABLE_SANDBOX_K8S_TEST_ONLY=true：使用指定构建的镜像元数据执行集群验证。
  • ENABLE_SANDBOX_K8S_TEST=false：显式跳过集群验证。
  • ENABLE_TEST_PYPI_PUBLISH=false：跳过 wheel 发布任务。

此分支不生成 openyuanrong-sdk wheel、SDK 缓存预编译任务或 Python ABI runtime 镜像矩阵，也不运行该 SDK 的 off-cluster actor smoke。Build X86/arm 通过 BUILD_PYTHON_SDK_WHEEL=0 关闭 SDK wheel 打包；控制面仍使用的运行时组件装配保持完整。其他直接调用 build.sh 的流程默认保留 SDK wheel 打包。
